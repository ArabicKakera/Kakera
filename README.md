# موقع الشظية العربية

كل الملفات في مستوى واحد بدون مجلدات: ارفعها كلها مباشرة إلى المستودع.

## إضافة تعريب جديد
1. افتح `data.js` وانسخ أي لعبة من القائمة `GAMES` والصقها في أولها ثم عدّل بياناتها.
2. ارفع صور الغلاف واللقطات بجانب الملفات واكتب أسماءها في بيانات اللعبة.

## الملفات
- `index.html` الرئيسية، `games.html` الألعاب، `game.html` المقال، `team.html` نبذة عن الفريق
- `style.css` التصميم، `data.js` بيانات الألعاب، `app.js` الكود
